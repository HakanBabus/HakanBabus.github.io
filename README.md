## 🚀 GitHub Pages Üzerinde Yayına Alma (2 Dakikada)

Bu projeyi doğrudan `https://HakanBabus.github.io` adresinde canlıya almak için aşağıdaki adımları uygulayabilirsiniz:

### 1. GitHub'da Depo Oluşturun
1. GitHub'a gidin: [github.com/new](https://github.com/new)
2. **Repository name** kısmına birebir şunu yazın:
   ```text
   HakanBabus.github.io
   ```
3. Depoyu **Public** seçin ve **Create repository** butonuna tıklayın.

### 2. Yerel Dosyaları Depoya Gönderin (Git ile)
Terminalde bu klasörün (`HakanBabus.github.io`) içine girip sırasıyla şu komutları çalıştırın:

```bash
git init
git add .
git commit -m "feat: launch Apple-grade personal portfolio"
git branch -M main
git remote add origin https://github.com/HakanBabus/HakanBabus.github.io.git
git push -u origin main
```

*(Eğer Git kullanmak istemiyorsanız, doğrudan GitHub'da deponun içine girip `index.html`, `style.css` ve `script.js` dosyalarını web arayüzünden sürükleyip bırakarak yükleyebilirsiniz).*

### 3. Siteniz Hazır! 🎉
GitHub Pages otomatik olarak sitenizi 1-2 dakika içinde derleyip yayına alacaktır:
👉 **https://HakanBabus.github.io**
